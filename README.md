# 4ДФ Калькулятор (BlackSea) — квартальна версія

Сервіс формує **Об'єднаний звіт (4ДФ)** для податкової з виписки Монобанку.
ФОП Мірошниченко Євгенія Василівна · РНОКПП 2482911060 · КВЕД 46.19 · ставки ПДФО 18% / ВЗ 5%.

Це один HTML-файл — `index.html`. Нічого встановлювати не треба:
відкрийте його у браузері (подвійний клік) або скористайтеся онлайн-версією нижче.
Дані нікуди не передаються — усе рахується локально у вашому браузері.

**Онлайн (GitHub Pages):** https://lalimi.github.io/4df/

## Як користуватися

1. У Монобанк-бізнес вивантажте **виписку за весь квартал** у форматі **.xlsx**.
2. Відкрийте `index.html` (або онлайн-версію), перетягніть файл виписки.
3. Оберіть **квартал** (напр. «II квартал (кві–чер)») і **рік**.
4. Натисніть **«Обробити квартал»**.
5. Перевірте таблиці по кожному місяцю та звірку ПДФО/ВЗ.
6. Експорт:
   - **Excel** — зведення + окремий аркуш на кожен місяць;
   - **XML** — головна форма F0500110 + **3 місячні додатки 4ДФ** (F0510410);
   - **TSV** (кнопка під кожним місяцем) — для ручного внесення в Кабінет ДПС / M.E.Doc.

## Що змінилось (квартальна подача 2026)

З 2026 року ФОП подають **один Об'єднаний звіт за квартал, але з розбивкою по місяцях**.
Тобто за квартал подається **три окремі додатки 4ДФ** — за перший, другий і третій місяць.
Попередня версія калькулятора рахувала лише **один** місяць — тепер він обробляє
весь квартал і будує по одному додатку 4ДФ на кожен місяць.

## ⚠️ Важливо перевірити перед подачею

- **XML — чернетка.** Електронні формати квартальних форм 2026 оновлюються ДПС.
  Обов'язково відкрийте/перевірте згенерований XML у **Кабінеті ДПС** перед відправкою.
  Найнадійніше — внести числа вручну (з таблиць або TSV), а XML сформує сама програма ДПС.
  Поля, які варто звірити зі схемою: `PERIOD_TYPE`, `PERIOD_MONTH`, наявність пооособових
  рядків у головній формі, ознака доходу.
- **Ознака доходу `127`** зашита за замовчуванням — підтвердьте, що вона актуальна.
- **gross = net / 0,77.** Інструмент вважає суми з банку сумою «на руки» (net) і донараховує
  ПДФО+ВЗ зверху. Це автоматично звіряється з реальними бюджетними платежами (кат. C/D).
  Якщо звірка «в нормі» ✅ — припущення підтверджено. Якщо ні — перевірте, чи всі платежі
  до бюджету потрапили у виписку.
- Перевірте **призначення платежів** у виписці: класифікація спирається на текст
  «Виплата частки фізичній особі … через платформу BlackSea».

## Класифікація операцій

| Кат. | Що це | Дія |
|---|---|---|
| A | Виплата фізособі (продаж контенту) | Іде в 4ДФ, групується по РНОКПП |
| B | Виплата ФОПу | Не в 4ДФ фізосіб |
| C | ПДФО до бюджету | Звірка з розрахованим ПДФО |
| D | ВЗ до бюджету | Звірка з розрахованим ВЗ |
| E | Інше | Ігнорується |
